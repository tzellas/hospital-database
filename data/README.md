# Seed data

Everything `sql/load.sql` loads lives here. All patient and staff records are **synthetic**; reference datasets come from public sources. Text in the ICD-10 and KEN tables is in Greek.

## Reference data (public sources)

| File | Loaded into | Notes |
|---|---|---|
| `icd10.csv` | `icd10_diagnosis` | ICD-10 diagnosis codes and descriptions |
| `ken.csv` | `ken` | Greek DRG-style inpatient cost categories: base cost and average length of stay |
| `drug.csv` | `drug` | Cleaned EMA register, products authorised in Greece |
| `full_ema.csv` | — | Full EMA export, kept for reference; not loaded |
| `active_substances_unique.csv` | `active_substance` | Unique active substances parsed from the EMA data |
| `drug_active_substances_stage.csv` | `drug_active_substance` | Staging file linking drugs to substances; resolved to IDs by `load.sql` |
| `all_actions.xls` | — | Raw official list of medical actions; input to `scripts/generate_procedures_and_lab_csvs.py` |
| `medical_procedures.csv` | `all_medical_procedures` | Procedure catalogue, classified by rules; costs are synthetic and seeded |
| `lab_tests.csv` | `all_lab_tests` | Lab-test catalogue; costs are synthetic and seeded |
